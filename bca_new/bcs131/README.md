## 🎯 Course Curriculum & Syllabus Structure

As published on IGNOU's eGyanKosh repository, BCS-131 follows the **3-Block, 11-Unit curriculum** identical to BCS-031:

### 📦 Block 1: Basics of Object Oriented Programming & C++
- **Unit 1:** Object Oriented Programming Paradigm ([Module 6: OOP Concepts](/bca_new/bcs131/topics/06-oop-concepts.md))
- **Unit 2:** Introduction to C++ Basics, Operators & Control Flow ([Module 4: Basics](/bca_new/bcs131/topics/04-basics-control-flow.md) & [Module 9: Functions](/bca_new/bcs131/topics/09-functions-overloading.md))
- **Unit 3:** Classes, Objects, Access Control, Friend & Static Members ([Module 1: Classes & Objects](/bca_new/bcs131/topics/01-classes-objects.md))
- **Unit 4:** Constructors, Destructors & Memory Management ([Module 3: Constructors](/bca_new/bcs131/topics/03-constructors-memory.md))

### 📦 Block 2: Inheritance and Polymorphism in C++
- **Unit 1:** Inheritance & Code Reusability ([Module 7: Inheritance](/bca_new/bcs131/topics/07-inheritance.md))
- **Unit 2:** Operator Overloading ([Module 11: Operator Overloading](/bca_new/bcs131/topics/11-operator-overloading.md))
- **Unit 3:** Polymorphism, Virtual Functions & Abstract Classes ([Module 2: Polymorphism](/bca_new/bcs131/topics/02-polymorphism.md))

## 🚨 The June 2026 Exam Format Shift

<div class="callout callout-important">
  <strong>Critical Exam Alert:</strong> In the June 2026 paper, IGNOU replaced the old pattern of eight 5-mark short questions with <strong>twelve 10-mark long-answer questions</strong> (4 in compulsory Question 1, and 2 each in Q2–Q5).
</div>

To score maximum marks, ensure you write:
1. **Formal Definition & Need** (2 marks)
2. **Syntax & Rules** (2 marks)
3. **Complete Compilable C++ Code Snippet** with `#include <iostream>`, `class` and `main()` (4 marks)
4. **Merits / Output / Constraints** (2 marks)
