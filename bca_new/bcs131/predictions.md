# 🎯 High-Probability Exam Predictions

> **Synthesizing historical frequency, recency gaps across the last five sessions (Jun 2024–Jun 2026), and the June 2026 shift toward 10-mark bundled questions**, the 12 targets below represent the strongest candidates for the next BCS-131 / BCS-031 Term-End Examination.

---

## 📌 Structural Analysis & The June 2026 Format Shift

A major structural shift occurred in the **June 2026** paper. Whereas exams from June 2019 through December 2025 relied heavily on 4- and 5-mark short questions (eight 5-mark questions in compulsory Q1 and short notes in Q5), **June 2026 converted the entire paper into twelve 10-mark long-answer questions** (four in compulsory Q1, two each in Q2–Q5).

> 

**Preparation Rule:** Prepare every high-frequency concept at **10-mark depth**—combining formal definitions, syntax rules, advantages/drawbacks, and complete compilable C++ code.

---

## 🔮 Top 12 High-Probability Targets

### #1. Friend Function, Merits/Demerits & Program

**Target #1** **Q002 / Q016 / Q018** **Classes & Objects**

**🔍 Historical Rationale & Gap Analysis:**

Friend-function questions appeared 20 times across CLASSES (Q002 alone 10x), yet were absent from all five papers between Jun 2024 and Jun 2026 (last seen Dec 2023).

**📝 Expected Question Format (10 Marks):**

A 10-mark bundled question asking for formal definition, two merits/demerits, and a complete C++ program (summing n numbers or bridging two classes with friend).

### #2. Access Control Specifiers (public, private, protected) in Class & Inheritance

**Target #2** **Q001 / Q146** **Classes & Inheritance**

**🔍 Historical Rationale & Gap Analysis:**

Q001 is the second most-repeated question overall (15x), yet was skipped in both Dec 2025 and Jun 2026, while derivation visibility modes (Q146) have not appeared since Dec 2021.

**📝 Expected Question Format (10 Marks):**

A combined 10-mark question covering class accessibility rules, default visibility in struct vs class, and how visibility modes change in inheritance derivation.

### #3. Operator Overloading Rules, Barred Operators & Program

**Target #3** **Q203 / Q205 / Q204 / Q206** **Operator Overloading**

**🔍 Historical Rationale & Gap Analysis:**

General operator overloading rules (Q203, 7x) and non-overloadable operators (Q205, 3x) were absent across the last five papers (last seen Dec 2023).

**📝 Expected Question Format (10 Marks):**

Rules + barred operators (::, ., .*, ?:, sizeof) paired with overloading unary minus (-) or binary plus (+) on Complex or String classes.

### #4. Encapsulation vs. Information Hiding

**Target #4** **Q136 / Q141 / Q144** **OOP Paradigms**

**🔍 Historical Rationale & Gap Analysis:**

Asked 6 times historically, Q136 has been absent for the last five papers (last seen Jun 2023).

**📝 Expected Question Format (10 Marks):**

Paired with class-based data hiding (Q144) or a small library/account code example illustrating how private members achieve information hiding through encapsulation.

### #5. Message Passing in C++ with Example

**Target #5** **Q135** **OOP Paradigms**

**🔍 Historical Rationale & Gap Analysis:**

Asked 12 times overall and skipped in Jun 2026, message passing is one of IGNOU's most consistent OOP conceptual anchors.

**📝 Expected Question Format (10 Marks):**

A 10-mark OOP interface and object-communication question explaining method calls, receiver objects, parameters, and demonstration code.

### #6. Exception Handling — Modified Variant

**Target #6** **Q195 / Q196 / Q197 / Q200** **Exception Handling**

**🔍 Historical Rationale & Gap Analysis:**

Exception handling appeared in all 5 of the last 5 papers. Because Jun 2026 tested the basic form (Q194), the next cycle is likely to rotate to a specialized variant.

**📝 Expected Question Format (10 Marks):**

Divide-by-zero (Q196), catch-all catch(...) (Q197), multiple catch blocks (Q200), or explaining std::terminate() when an exception is thrown outside try (Q195).

### #7. Abstract Class + Pure Virtual Program OR Virtual salary() Hierarchy

**Target #7** **Q040 / Q042** **Polymorphism**

**🔍 Historical Rationale & Gap Analysis:**

Because Jun 2026 tested pure theory on abstract classes (Q044) and virtual vs. pure virtual (Q043), the cycle strongly favors a 10-mark coding hierarchy.

**📝 Expected Question Format (10 Marks):**

Implementing either an abstract Shape class (Circle/Rectangle area) or the Employee/Teacher/Doctor virtual salary() hierarchy with base pointer dispatch.

### #8. Function Overloading vs. Overriding OR Compile-Time vs. Run-Time Polymorphism

**Target #8** **Q041 / Q047** **Polymorphism**

**🔍 Historical Rationale & Gap Analysis:**

Q041 (7x, last seen Jun 2024) and Q047 (4x, last seen Jun 2021) are overdue. POLY_VIRT generates 17.5% of recent marks.

**📝 Expected Question Format (10 Marks):**

A comprehensive 10-mark comparison table paired with two distinct code examples illustrating early vs late binding.

### #9. Class Template (Stack / LinkedList / Sort) & Class vs. Function Template

**Target #9** **Q120 / Q121 / Q117** **Templates & STL**

**🔍 Historical Rationale & Gap Analysis:**

Jun 2026 tested function templates (Q118), pointing toward a rotation to Class Template data structures or Class vs Function Template comparison.

**📝 Expected Question Format (10 Marks):**

Generic Stack template class with push()/pop() methods or singly LinkedList template implementation.

### #10. STL Containers & list Container Program

**Target #10** **Q115 / Q119** **Templates & STL**

**🔍 Historical Rationale & Gap Analysis:**

TEMPL_STL has appeared in 30/30 papers, yet containers (Q115, 7x) were omitted in Jun 2026.

**📝 Expected Question Format (10 Marks):**

Container taxonomy (Sequence, Associative, Derived) plus member functions (push_back, insert, erase) or a list container demonstration program.

### #11. File Handling Program (Append / Copy / Read-Write) + File Pointers

**Target #11** **Q168 / Q173 / Q171** **Streams & Files**

**🔍 Historical Rationale & Gap Analysis:**

Jun 2026 covered only stream manipulators (Q169) and skipped file I/O coding. File programs rotate predictably.

**📝 Expected Question Format (10 Marks):**

A 10-mark program opening an existing file and appending a string (ios::app), copying files, or explaining seekg/seekp/tellg/tellp.

### #12. Static Members (Q004) OR Constructor Overloading / Destructors (Q063 / Q060)

**Target #12** **Q004 / Q060 / Q063** **Classes / Constructors**

**🔍 Historical Rationale & Gap Analysis:**

Both Q004 (6x, 47 marks) and Q060 (7x) were absent from Jun 2026 and fit the 10-mark theory-plus-program format perfectly.

**📝 Expected Question Format (10 Marks):**

Program demonstrating static count variable across objects, or constructor overloading with a dynamic destructor freeing heap memory.
